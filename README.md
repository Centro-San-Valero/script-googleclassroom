# Instrucciones para ejecutar el script

Este script está creado con **Google Apps Script**, una herramienta de Google que permite automatizar tareas de Google Workspace, por ejemplo en Google Classroom, Drive, Gmail o Google Sheets.

No es necesario saber programar para utilizarlo. Solo hay que seguir estos pasos.

## 1. Abrir el script

Accede al siguiente enlace utilizando tu cuenta de Google:

**[Abrir el script de Google Apps Script](https://script.google.com/u/1/home/projects/1HcaEQQ1odZD8A0F1kLG_r8QFJqhjVp1q35tx9GukaKLnxIWtQ_6UIiAW/edit)**

> Es importante utilizar la cuenta de Google con la que tengas acceso a los recursos sobre los que va a trabajar el script.

---

## 2. No modificar el código

Al abrir el enlace aparecerá una pantalla con código.
